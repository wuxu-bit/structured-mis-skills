# DBHub Read-Only Validation

## 上游

- Repository: https://github.com/bytebase/dbhub
- License: MIT

安装和配置必须以当前上游文档为准。本仓库不分发DBHub，也不固定一个未经当前环境测试的版本号。

## 防御纵深

必须同时具备：

1. 数据库专用只读角色；
2. DBHub只读限制；
3. 查询行数上限；
4. 查询超时；
5. 测试或staging优先；
6. DSN从本地秘密来源读取；
7. 固定并记录经过测试的版本。

仅在提示词里写“只读”不构成安全控制。若DBHub仍连接应用写账号，验证Gate失败。

## 禁止回退

不要采用：

```text
READONLY_DSN为空时自动使用DATABASE_URL
```

缺少只读DSN应直接失败，不能静默升级权限。

## 验证范围

只读查询可以验证：

- 当前数据库用户和事务只读状态；
- 表和列；
- 类型、长度、精度、默认值和可空性；
- 主键、外键、唯一约束和索引；
- Prisma迁移历史；
- 合成Seed数据计数；
- 孤立外键、非法状态和重复唯一键候选。

## 先验证权限

在查询业务结构前，确认：

- 当前用户只能读取目标Schema；
- INSERT、UPDATE、DELETE和DDL权限均不可用；
- 查询范围和超时生效。

不要为了测试“不可写”而对共享数据库执行真实破坏性语句。优先查询权限目录和事务只读状态。

## 配置请求模板

```text
请按官方文档把DBHub配置为当前项目的只读数据库验证MCP：
https://github.com/bytebase/dbhub

只创建项目级配置；固定经过测试的版本；从本地环境变量读取专用只读DSN；启用DBHub只读、行数和超时限制；不要输出DSN；不要执行迁移、DDL、DML或Seed。
```

## 证据记录

记录DBHub版本、Node版本、数据库产品和版本、只读用户名称（不含密码）、验证时间、查询类别和结果摘要。
