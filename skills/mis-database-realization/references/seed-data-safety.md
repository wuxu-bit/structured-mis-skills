# Seed Data Safety

## 数据来源

Seed只使用合成数据，不复制真实用户、访谈、交易、手机号、学号、地址或截图中的数据。生成规则写入文档。

## 可复现性

- 固定随机种子或使用明确静态样例。
- 不依赖某次运行产生的自增ID。
- 通过唯一业务键查询关联对象。
- 注释中的数量由脚本或测试计算，不手写过期数字。
- 每个状态至少有必要的代表样例。

## 重复运行

明确选择一种策略：

1. 幂等upsert；
2. 独立测试数据库重建；
3. 明确的删除后重建。

删除后重建是破坏性操作，必须确认目标数据库、备份边界和执行授权。多表删除或重建尽量使用事务；无法单事务完成时记录恢复策略。

## 引用完整性

- 不用固定数字猜测新生成记录ID。
- 关联对象通过返回值或唯一键获得。
- Seed结束后验证外键、唯一性和业务状态组合。
- 失败时清楚报告已经写入的范围。

## 环境

- 本地开发和专用测试库可以Seed。
- staging需明确审批。
- 生产默认禁止Seed、reset和示例账号创建。
